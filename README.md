# Проекты на 1С:Предприятие 8.3

Учебные конфигурации по дисциплине «Корпоративные информационные системы».

## Школа танцев

Информационная система для танцевальной студии: расписание занятий, продажа абонементов, учёт посещений и аналитические отчёты. Конфигурацию дорабатывала: добавлен срок действия абонементов, контроль остатка занятий, отчёты для руководства и разграничение прав доступа.

В папке `dance-school/`:
- `Техническое задание.pdf`: ТЗ на автоматизированную систему управления школой танцев.
- `Описание реализации.pdf`: объекты конфигурации (справочники, документы, регистры, отчёты).
- `Инструкция по использованию.pdf`: работа с системой по шагам.
- `Отчёт о доработке конфигурации.pdf`: описание добавленного функционала.
- `Школа танцев.dt`: выгрузка информационной базы с тестовыми данными.

## Театральный колледж

Конфигурация для автоматизации приёмных испытаний колледжа: регистрация абитуриентов со сканом диплома, учёт вступительных испытаний с баллами участников и отчёт с итоговой суммой баллов для передачи на зачисление.

В папке `theatre-college/`:
- `Отчёт.pdf`: описание реализованных объектов метаданных.
- `Театральный колледж.dt`: выгрузка информационной базы.

## Как открыть конфигурацию

1. Установить [1С:Предприятие 8.3 (учебная версия)]([https://edu.1c.ru/](https://online.1c.ru/catalog/free/28765768/)).
2. Создать пустую информационную базу и открыть её в режиме «Конфигуратор».
3. В меню «Администрирование» выбрать «Загрузить информационную базу» и указать файл `.dt`.
4. Запустить базу в режиме «1С:Предприятие».
